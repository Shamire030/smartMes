# Smart MES 项目技术实现文档

## 1. 项目概述

Smart MES（Manufacturing Execution System）是一款基于现代信息技术的智能制造执行系统，旨在帮助制造企业实现生产过程的数字化、可视化和智能化管理。该系统集成了生产计划、生产执行、质量管理、设备管理和数据分析等核心功能模块，为企业提供全面的生产管理解决方案。

## 2. 技术架构

### 2.1 系统整体架构

Smart MES 采用前后端分离的架构模式，实现了业务逻辑与界面展示的解耦，提高了系统的可维护性和扩展性。

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  前端应用   │────▶│  后端服务   │────▶│  数据库     │
│ (Vue 3)     │◀────│ (Spring Boot)│◀────│ (MySQL)     │
└─────────────┘     └─────────────┘     └─────────────┘
```

## 3. 后端核心功能实现

### 3.1 数据模型设计

后端采用面向对象的数据模型设计，每个模型类对应数据库中的一个表，使用Lombok注解简化代码：

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class ProductionPlan {
    private Long id;
    private String planNo;
    private String productId;
    private String productName;
    private Integer planQuantity;
    private Date startDate;
    private Date endDate;
    private String status;
    private Date createTime;
    private Date updateTime;
}
```

### 3.2 数据访问层

使用MyBatis作为ORM框架，通过Mapper接口和XML配置文件实现数据访问：

```java
@Mapper
public interface ProductionPlanMapper {
    int insert(ProductionPlan productionPlan);
    int update(ProductionPlan productionPlan);
    int deleteById(Long id);
    ProductionPlan selectById(Long id);
    List<ProductionPlan> selectAll();
    List<ProductionPlan> selectByStatus(String status);

```

### 3.3 业务逻辑层

服务层封装了核心业务逻辑，实现了对数据的处理和业务规则的验证：

```java
@Service
public class ProductionPlanServiceImpl implements ProductionPlanService {
    @Autowired
    private ProductionPlanMapper productionPlanMapper;

    @Override
    public Result addProductionPlan(ProductionPlan productionPlan) {
        // 业务逻辑验证
        if (productionPlan.getPlanQuantity() <= 0) {
            return Result.error(ResponseCode.PARAM_ERROR, "计划数量必须大于0");
        }
        // 数据处理
        productionPlan.setCreateTime(new Date());
        productionPlan.setUpdateTime(new Date());
        productionPlan.setStatus("PENDING");
        // 数据持久化
        int result = productionPlanMapper.insert(productionPlan);
        if (result > 0) {
            return Result.success("生产计划添加成功");
        } else {
            return Result.error(ResponseCode.SYSTEM_ERROR, "生产计划添加失败");
        }
    }
    // 其他业务方法...
}
```

### 3.4 控制层

控制层处理HTTP请求，调用服务层完成业务逻辑，并返回统一格式的响应：

```java
@RestController
@RequestMapping("/api/production-plan")
@Tag(name = "生产计划管理", description = "生产计划相关接口")
public class ProductionPlanController {
    @Autowired
    private ProductionPlanService productionPlanService;

    @PostMapping
    @Operation(summary = "添加生产计划", description = "添加新的生产计划")
    public Result addProductionPlan(@RequestBody ProductionPlan productionPlan) {
        return productionPlanService.addProductionPlan(productionPlan);
    }

    @GetMapping
    @Operation(summary = "获取所有生产计划", description = "获取系统中所有的生产计划")
    public Result getAllProductionPlans() {
        return productionPlanService.getAllProductionPlans();
    }
    // 其他接口方法...
}
```

## 5. 安全机制

### 5.1 身份验证与授权

使用JWT（JSON Web Token）进行身份验证与授权：

```java
@Service
public class AuthService {
    @Autowired
    private UserService userService;

    public Result login(String username, String password) {
        // 验证用户身份
        User user = userService.getUserByUsername(username);
        if (user == null || !user.getPassword().equals(password)) {
            return Result.error(ResponseCode.AUTH_ERROR, "用户名或密码错误");
        }
        // 生成JWT令牌
        String token = Jwts.builder()
                .setSubject(username)
                .setExpiration(new Date(System.currentTimeMillis() + 86400000)) // 24小时过期
                .signWith(SignatureAlgorithm.HS512, "secret_key")
                .compact();
        return Result.success("登录成功", token);
    }
}
```

### 5.2 跨域资源共享

配置CORS（Cross-Origin Resource Sharing）支持前端跨域请求：

```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.addAllowedOrigin("*");
        config.addAllowedMethod("*");
        config.addAllowedHeader("*");
        config.setAllowCredentials(true);
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/api/**", config);
        return new CorsFilter(source);
    }
}
```
